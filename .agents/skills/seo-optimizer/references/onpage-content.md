# On-page & SEO-optimized Content

## Step 1: Define before writing
Ask/confirm clearly:
- **Primary keyword** and 2-4 related secondary keywords (LSI/semantic keywords)
- **Search intent**: Informational (learning), Navigational (finding a specific site), Commercial (comparing before buying), Transactional (ready to buy/act now)
- Use web_search to check the current top 5-10 results for that keyword → infer what format Google is currently prioritizing (list, guide, review, landing page...)

## Step 2: Page structure

**Title tag**
- 50-60 characters, contains the primary keyword, placed as close to the front as possible
- Compelling, but not clickbait that misrepresents content (Google penalizes content that doesn't match the title)

**Meta description**
- 120-158 characters, contains the primary keyword, includes a call-to-action (CTA)
- Doesn't directly affect ranking but influences CTR (click-through rate)

**URL**
- Short, contains the keyword, uses hyphens, avoids messy parameters

**Headings (H1-H3)**
- Only one H1 containing the primary keyword
- H2/H3 break down content according to the sub-questions/points readers care about (good for both UX and featured snippets)

**Opening paragraph**
- Answer the main point directly within the first 1-2 sentences (good for featured snippets + retaining readers)

## Step 3: Content quality (most important)

- **Length**: there's no magic number — length should be enough to fully address search intent; informational articles typically do well at 1200-2500 words, but completeness matters more than length
- **E-E-A-T**: demonstrate real experience (examples, data, actual photos), cite credible sources, have clear author info (bio, expertise)
- **Avoid unmoderated mass AI content**: Google doesn't ban AI content but penalizes low-quality/formulaic content mass-produced to manipulate rankings — always edit, add real value (case studies, proprietary data, expert perspective)
- **Uniqueness**: avoid rehashing competitor content; add perspectives/data that other articles don't have

## Step 4: Internal linking
- Link to 3-5 related pages within the site using descriptive anchor text (not "click here")
- New pages should be linked from at least one high-authority page on the site (homepage, category page)

## Step 5: Images & media
- Descriptive alt text that naturally includes keywords (serves accessibility + Google Images)
- Compress images (WebP), use lazy-loading so it doesn't hurt load speed

## Step 6: Schema markup (structured data)
- Add appropriate schema for the content type: Article, FAQPage, HowTo, Product, Review... helps Google understand content and can enable rich snippets
